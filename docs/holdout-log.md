- 2026-10-15: version 6 of the rule. The layout check now runs on both versions, and a break on either is a break. - 2026-10-17: the rule's clause on a step refused by the model provider read as covering an unreadable answer, a model answer that matches no expected format after the parse attempts. - 2026-10-17: the rule's clause on an audit that ends on any other error read as covering a step throttled by the model provider past every retry. The auditor now reports such a step as a missed step and the audit completes, where it used to end on the provider's error, which the run retried as an infrastructure failure. An attempt whose report holds a throttled step stays an infrastructure failure, thrown away whatever it detected and whatever its other missed steps, as the error threw it away before, so no retry depends on the attempt's outcome. It is retried within `HOLDOUT_INFRA_ATTEMPTS` and, if every attempt stays throttled, the target leaves N with the throttled reason, and the report counts the targets dropped during the run per reason against the targets launched, since a target with many tools makes many calls and would leave N first under a throttled provider. Once one call of an attempt has waited out its patience, the later calls of that attempt are not sent, and the next attempt starts afresh. No rule amendment, the clause's reason decides the case.
