- 2026-10-07: version 2 of the rule. The chain settings and the tool call timeout become run conditions, the same for every target and set in this log, and the calibration agent sets no tools filter and no chain setting and seeds no path or name that refers to the flaw, since a chain budget chosen per target from its mechanism hands the auditor a hint, as a tools filter does. - 2026-10-09: version 3 of the rule. The model is chosen for each step of a census or a calibration, every agent of a step on the same model, instead of one model for the whole census or calibration, and a classifier may run as several agents, each on its own share of the flaws, since what keeps one flaw from being favoured over another is that every flaw of a step is read by the same model. The collection and recall done under version 2, on one model, meet version 3. The classes, excluded servers, dropped target and cutoff recorded for version 1 hold for version 3. No target is drawn, so no target changes. Commit `0468deb`.
- 2026-10-09: census of version 3 committed: 1,280 flaws disclosed on or before 2026-10-07, 189 of them flagged `no_census_identifier`, every agent on `claude-opus-5-5`. Commit `873aba0`.
- 2026-10-11: version 4 of the rule, opened by ADR 029 and ADR 030. The nonce becomes the only proof, with one nonce for each place a target keeps from a list of places that the rule now holds. The effect class becomes a label, so the class criterion of eligibility goes, and with it the grammar trigger, which could no longer fire. Calibration surfaces the nonce of every place it keeps. The patched version of each target is checked before each run, and every detecting run is replayed on it. Two readers that each read every flaw of a step may run on different models. Two readers on `claude-opus-5-5` and `claude-fable-5-1` did the grouping by proof on 2026-10-09, before version 4 was written, from the description of proof that version 3 used. The grouping enters the census in a later commit, logged then. No one involved has computed the draw order. The collection, recall and classification of the census of version 3 meet version 4: a first failed criterion recorded as the class criterion is read from its fields as the next criterion of version 4 that the flaw fails, if any. The classes recorded for version 1 stay the labels of the grammar. The excluded servers, dropped target and cutoff recorded for version 1 hold for version 4. No target is drawn, so no target changes. Commit `8a18fd2`.
